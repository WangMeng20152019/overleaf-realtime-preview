## JavaScript dependencies and generated artifacts

[DEPENDENCY_LICENSES.json](docs/DEPENDENCY_LICENSES.json) inventories **all 49 non-root package entries** in the lockfile, including optional platform packages. Every entry declares MIT or Apache-2.0 in that lockfile. It records exact versions, npm integrity values, lock locations and available license-file hashes. This replaces the earlier 15-package installed-host list.

The 13 license/notice files available from installed packages are copied verbatim into [docs/licenses/](docs/licenses/). This includes the MIT notices for `opentype.js`, `ws`, CodeMirror and installed JavaScript transitives, plus the full Apache-2.0 text for `pdfjs-dist`. Optional packages absent on this review host were checked only through lockfile declarations, not unpacked or audited. In particular, native canvas/esbuild distributions and their bundled native dependencies have **not** received a binary redistribution review.

`node_modules/`, `dist/`, generated `public/app.js`, `public/integration.js`, `public/pdf.worker.mjs`, and generated preview output are excluded from the source publication set. Regenerated bundles must be accompanied by the applicable notices from this tree and their corresponding build source. The build currently embeds the `ws` notice into the server and preserves the copied PDF worker's Apache notice, but a browser bundle alone does not contain all upstream MIT notices. Do not distribute a standalone bundle without the accompanying license set. No PDF.js standard fonts, CMaps or native binaries are included in the source publication; adding them requires reviewing their separate notices.

## Publication limits

This source review found no targeted private-host, private-project, personal absolute-path, private-key or long literal credential patterns in the candidate text on 2026-11-10. This was a scoped scan, not proof that all secrets or source-origin problems are absent. Use an explicit publication allowlist from a fresh repository; `.gitignore` alone is not an archive filter. Remaining release conditions, including immutable Overleaf image/source provenance, source availability for deployed modifications, artifact notices, fresh installation and rollback acceptance, are tracked in [RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md).
