# 开发与归属说明

## 上游、发起者与 ChatGPT 各自做了什么

项目的基础来自 [realtime-tex](https://github.com/HenryXiaoYang/realtime-tex)、[Overleaf CE](https://github.com/overleaf/overleaf) 和 [realtime-tex-vsc-plugin](https://github.com/HenryXiaoYang/realtime-tex-vsc-plugin)：它们分别提供核心排版引擎、编辑平台和浏览器渲染模块。本项目不是独立开发的 TeX 引擎或协作编辑器，我们的工作主要在集成和下游工程这一层。上游作者对自己那部分工作保有署名。

**人（项目发起者）** 提供的是要做什么、在什么场景下用：提出使用需求，用真实的中文论文持续写作，把问题反馈回来，并在修改后继续验证，判断好不好用。这些反馈决定了后面调试什么、改什么。

**ChatGPT/Codex** 承担了大部分实现：集成代码的编写、补丁起草、调试和测试构造，也协助审查。人在实际写作中发现问题，AI 改代码，人再用真实文档验证，这样来回推进。需要说明的是，自动化审查不等于独立的外部审计；AI 参与也不是正确性保证。

**本集成的贡献** 集中在编辑器与预览的连接、源文件版本与排版结果的协调、恢复、导航、诊断和部署工具这些方面。涉及引擎的改动，都应描述为针对某个具体上游版本的下游补丁，而不是上游本身的行为。

## 记录的来源与局限

开发记录是定性的，来自实际讨论中给出的反馈和任务内的工程产物，不是对话逐字稿，不是受控用户研究，也不是完整的根因报告。私人论文正文、用户截图和原始诊断数据被有意排除在外。

AI 的参与在文档中显著披露。许可、发布、维护和审查的责任归仓库维护者。我们不声称生成的每一行代码都是原创或没有缺陷。
