# Changelog

## 0.1.0-alpha.2 — local privacy and environment organization

- Maps the reproducible environment, source responsibilities, public test files and evidence boundaries.
- Adds a read-only privacy gate for source, the exact staged Git index and matching archive; thirteen new regression cases.
- Keeps maintainer-specific terms and derived fingerprints in a protected local-only denylist, not public source.
- Adds read-only CI permissions, disables persisted checkout credentials and includes the publication gate.
- Documents private-only artifacts, diagnostic review and known isolation limits. Runtime integration/engine behavior is unchanged from the validated alpha.1 snapshot.

## 0.1.0-alpha.1 — local source release preparation

This is the first source-first experimental alpha. No GitHub release or universal installation acceptance is implied by this entry.

- Integrates upstream realtime-tex with Overleaf CE's existing right-hand PDF preview pane and a traditional/realtime mode switch.
- Adds downstream source/revision and capture-installation guards, editor integration, position mapping, recovery and diagnostics.
- Provides reproducible source selection, locked engine builds, matching TeX support, dependency-notice collection and immutable runtime inventories.
- Provides an isolated frontend build and project-bound installation, activation and route rollback for one exact CE source/image profile.
- Corrects the pinned CE image’s discarded invite-token settings using a guarded official one-line fix; verifies VFS memory separately from the sealed startup disk checkpoint.
- Recognizes English and Chinese native navigation controls; retains explicit limits for coarse environment mappings.
- Includes synthetic development fixtures, regression tests and an allowlisted deterministic source-release packager.
- Records the realtime-tex, Overleaf CE and renderer foundations, ChatGPT/Codex implementation assistance, and human-led requirements, use and bug feedback.

Fresh engine and installer-component results are recorded in [validation](docs/VALIDATION.md) and [compatibility](docs/COMPATIBILITY.md). The pinned fresh Compose installation passed the synthetic editor scenarios, rollback and container-restart checks. Real OS IME, more templates and multi-user use remain unverified. Navigation uses available engine unit mappings and is not precise SyncTeX. Historical private-server results are separate evidence. Realtime preview uses LuaLaTeX; no universal latency, template or CE-version guarantee is made.
